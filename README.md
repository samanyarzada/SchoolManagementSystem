# School Management System

A desktop-based **School Management System** developed with Java and JavaFX.

The application provides a graphical interface for managing students, teachers, courses, classrooms, attendance, enrollment, schedules, and reports.

## Features

- Student management
- Teacher management
- Full-time and part-time teacher management
- Course management
- Classroom management
- Student enrollment
- Attendance management
- Timetable and scheduling
- Reports
- Dashboard
- Login screen
- JavaFX graphical user interface

## Technologies

- **Java 26**
- **JavaFX 26.0.1**
- **Maven**
- **FXML**
- **Visual Studio Code**
- **Git & GitHub**

## Requirements

To build and run the project, you need:

- **JDK 26**
- **Maven 3.9+** or Maven Wrapper
- **Windows**
- **Visual Studio Code** with the Extension Pack for Java (recommended)

JavaFX dependencies are managed automatically through Maven.

You do not need to manually configure a JavaFX SDK path in the project.

## Running the Project

### Build the Project

Open a terminal in the project directory:

```cmd
mvn clean compile
```

If the build is successful, Maven will display:

```text
BUILD SUCCESS
```

### Run the Application

To start the JavaFX application:

```cmd
mvn javafx:run
```

Maven automatically downloads the required JavaFX dependencies from Maven Central.

### Login

The application currently provides a default login for testing:

```text
Username: admin
Password: 1234
```

These credentials are intended for demonstration and educational purposes.

### Run from VS Code

Open the project in Visual Studio Code.

The project can be built and run using the Maven/Java tools provided by VS Code.

You can also use the integrated terminal:

```cmd
mvn clean compile
mvn javafx:run
```

## Maven

The project uses Maven to manage dependencies and the build process.

JavaFX dependencies are defined in `pom.xml`, including:

- JavaFX Controls
- JavaFX FXML

This makes the project easier to build on another computer without relying on a machine-specific JavaFX SDK path.

## Notes

The `target/` directory is generated by Maven during the build process and is excluded from Git.

The project does not require a manually configured JavaFX SDK path when running through Maven.

The default login credentials are provided for demonstration and educational purposes.
